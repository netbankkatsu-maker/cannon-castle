# 灰の旅路 — 沈黙の城

正体不明の「灰の人」と記憶の魂が、崩壊する未来のために過去の城を攻略する、スマホ向け3D遠征ゲーム。

## ゲームの流れ

1. ホームの「魂の祭壇」で恒久強化し、「灰の器」に持ち込む弾と修理キットを選ぶ。
2. 城や兵士をタッチして砲撃。兵舎が残っている間は兵士が現れ、主砲を攻撃する。
3. 城が崩れると自動で3択の遺物へ。恩恵と代償がある遺物を1つ選ぶと、フェードと再生演出を挟んで次の日の城へ進む。
4. 主砲HPが0、または「帰還」でホームへ。魂片を持ち帰り、次の旅に備える。

コインは旅の強化用、魂片は恒久強化用です。「旅の強化網」18能力と通常の威力・連射・主砲自動、追加砲台、遺物は旅ごとに初期化します。「魂の祭壇」の8能力、所持魂片、最深到達日、既読の物語は残ります。

石弾は灰の重み1、鉄弾3、炸裂弾4、修理キット5。灰の器の初期容量は40、恒久強化で90まで増やせます。主砲と追加砲台は同じ弾薬を使い、二連射も1発ごとに消費します。残数0の弾は選べず、使い切ると残る種類へ切り替わります。修理キットはHP35を回復します。

## 城・戦闘・物語

5種類の建築を循環。木・レンガ・石の耐久と重さ、塔の倒壊、瓦礫の衝突、火薬庫の誘爆、宝物庫の報酬があります。上段構造70%以上かつ全体55%以上の崩壊でクリア。HP95%消失も保険条件です。

初日は固定、以降は城壁・兵舎・敵火力などの日ごとの変化を抽選します。会話は灰の人と記憶の魂のみ。城は話さず、王や支配者は登場しません。初回の案内から10日目の物語まで9章。会話、強化画面、配置、遺物選択中は戦闘が停止します。

## セーブ・音・PWA

localStorageへホームと遠征を自動保存。HP・残弾・修理キット・遺物・未選択の3択・日ごとの城の変化も保存します。城の物理状態と兵士の位置は保存せず、同じ日を原型から再開します。宝物とクリアボーナスの重複取得を防ぎます。旧v1のデータは消さず、初回移行時に攻略履歴から最大100魂片を付与します。ブラウザのデータ削除でセーブも消えます。

音は初回操作で有効化し、ヘッダーで消音できます。コインの吸い込み、連鎖に合わせた回収音、OSの「動きを減らす」に対応。

PWAはv10。初回オンラインでキャッシュが完成するとオフライン起動できます。全ローカルモジュールとWebP素材をキャッシュし、旧ゲームキャッシュを削除します。初回の準備には3Dライブラリを含む通信が必要です。

## 起動・公開

Node.js 20以上。npm依存パッケージのインストール不要。

```sh
npm test
npm run build
npm run dev
```

[ローカルゲーム](http://localhost:3000) を開きます。Three.js 0.160.1、cannon-es 0.20.0を固定CDNから読み込み。WebGL不可時はCPU描画へ切り替えます。`?castle=1`〜`5` は保存しない建築プレビューです。

VercelはGitHub mainと連携済み。Other / `npm run build` / `dist`、環境変数不要。mainへのpushで本番更新します。公開先は https://cannon-castle.vercel.app/ です。

## 素材・検証

9点の生成原本とプロンプトを `src/assets/` に保存。配信用は見た目とアルファを保ったlossless WebPで約12.5MB（PNG原本20.4MB）。既存のPWAアイコンも生成素材から更新。描画倍率1.4、敵12体・敵弾24・自弾80・粒子180・コイン演出24で上限。

単体テスト53件と静的ビルド成功。ブラウザで容量超過の出発防止、敵攻撃、HP0帰還、魂片の持ち帰り、恒久強化と旅の初期化、会話、クリア→保存される3択→選択→フェード→次の日を確認。サブエージェントが生成素材、ホーム、恒久強化、スマホ用CSSを評価しました。仕上げの一部ブラウザ操作は接続不調で再確認できていません。実機iPhoneのPWA・機内モード・音・FPSと、長期の難度・価格バランスは未確認です。
