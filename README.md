# 灰の旅路 — 沈黙の城

正体不明の「灰の人」と記憶の魂が、崩壊する未来のために過去の城を攻略する、スマホ向け3D遠征ゲーム。

## ゲームの流れ

1. ホームの「魂の祭壇」で恒久強化し、「灰の器」に持ち込む弾と修理キットを選ぶ。
2. 城や兵士をタッチして砲撃。兵舎が残っている間は兵士が現れ、主砲を攻撃する。
3. 城が崩れると核が解放され、短い演出のあと自動で3択の遺物へ。恩恵と代償がある遺物を1つ選ぶと、フェードと再生演出を挟んで次の日の城へ進む。
4. 主砲HPが0、または「帰還」でホームへ。魂片を持ち帰り、次の旅に備える。

刻印片は旅の強化用、魂片は恒久強化用です。「旅の強化網」18能力と通常の威力・連射・主砲自動、追加砲台、遺物は旅ごとに初期化します。「魂の祭壇」の8能力、所持魂片、最深到達日、既読の物語は残ります。

石弾は灰の重み1、鉄弾3、炸裂弾4、修理キット5。灰の器の初期容量は40、恒久強化で90まで増やせます。主砲と追加砲台は同じ弾薬を使い、二連射も1発ごとに消費します。残数0の弾は選べず、使い切ると残る種類へ切り替わります。修理キットはHP35を回復します。

## 城・戦闘・物語

5種類の建築を循環。木・レンガ・石の耐久と重さ、塔の倒壊、瓦礫の衝突、火薬庫の誘爆があります。各城の壁の奥に技術装置4基と核を配置。装置と兵舎を壊すと刻印片、核を壊すと魂片を得ます。通常の岩へのダメージや兵士撃破では報酬を得ません。装置は淡い刻印の輪で見分けられます。上段構造70%以上かつ全体55%以上の崩壊でクリア。HP95%消失も保険条件です。

初日は固定、以降は城壁・兵舎・敵火力などの日ごとの変化を抽選します。会話は灰の人と記憶の魂のみ。城は話さず、王や支配者は登場しません。初回の案内から10日目の物語まで9章。会話、強化画面、配置、遺物選択中は戦闘が停止します。

## セーブ・音・PWA

localStorageへホームと遠征を自動保存。HP・残弾・修理キット・遺物・未選択の3択・日ごとの城の変化も保存します。城の物理状態と兵士の位置は保存せず、同じ日を原型から再開します。装置と核の回収履歴を保存し、組み直し・再開時の重複取得を防ぎます。旧v2の残高と強化を保持し、宝物履歴を手前の装置、クリア履歴を核と装置の回収済み扱いに引き継ぎます。旧v1のデータは消さず、初回移行時に攻略履歴から最大100魂片を付与します。ブラウザのデータ削除でセーブも消えます。

音は初回操作で有効化し、ヘッダーで消音できます。灰白色の刻印片の吸い込み、連鎖に合わせた控えめな回収音と核解放音、OSの「動きを減らす」に対応。

PWAはv13。初回オンラインでキャッシュが完成するとオフライン起動できます。全ローカルモジュールとWebP素材をキャッシュし、旧ゲームキャッシュを削除します。初回の準備には3Dライブラリを含む通信が必要です。

## 起動・公開

Node.js 20以上。npm依存パッケージのインストール不要。

```sh
npm test
npm run build
npm run dev
```

[ローカルゲーム](http://localhost:3000) を開きます。Three.js 0.160.1、cannon-es 0.20.0を固定CDNから読み込み。WebGL不可時はCPU描画へ切り替えます。`?castle=1`〜`5` は保存しない建築プレビューです。

VercelはGitHub mainと連携済み。Other / `npm run build` / `dist`、環境変数不要。mainへのpushで本番更新します。公開先は https://cannon-castle.vercel.app/ です。

## 素材・検証

9点の生成原本とプロンプトを `src/assets/` に保存。配信用は見た目とアルファを保ったlossless WebPで約12.5MB（PNG原本20.4MB）。既存のPWAアイコンも生成素材から更新。描画倍率1.4、敵12体・敵弾24・自弾80・粒子180・破片・光輪演出24で上限。

単体テスト60件と静的ビルド成功。ブラウザで容量超過の出発防止、敵攻撃、HP0帰還、魂片の持ち帰り、恒久強化と旅の初期化、会話、クリア→保存される3択→選択→フェード→次の日を確認。サブエージェントが生成素材、ホーム、恒久強化、スマホ用CSSを評価しました。仕上げの一部ブラウザ操作は接続不調で再確認できていません。実機iPhoneのPWA・機内モード・音・FPSと、長期の難度・価格バランスは未確認です。

## v11 報酬変更の検証

装置5箇所（技術装置4・兵舎1）へ旧方式の全回収相当予算を10/15/20/30/25%で分配。刻印増収は技術装置だけ、連鎖破壊・遺物・日ごとの収益倍率は刻印片へ適用。核の魂片は旧ブロック全破壊相当を基準にし、魂獲得倍率を適用。未回収装置の刻印片はクリア時に付与せず、追加のクリア通貨もありません。核の先行破壊では勝利せず、既存の構造判定で3択へ進みます。核が残っていてもクリア時に追加弾なしで解放します。

単体テストとビルド成功。320px幅の実ブラウザで表示と砲撃を確認。サブエージェントが320/375pxのCSS・演出上限・減 motionを確認。実ブラウザ接続が不安定なため、装置回収から購入・核解放・遺物選択までの一連の実操作と375pxの最終画像、実機iPhone・長期バランスは追加確認が必要です。この報酬変更は操作ガイドと合わせて公開しています。

## v13 初めての操作ガイド（2026-10-28）

初回は目的を短く示し、安全な練習へ案内します。既存プレイヤーには強制表示せず、ホーム/戦闘下部の「操作ガイド」から再確認できます。物語とは別の12操作：石弾10→修理1→出発→城壁を砲撃→装置を壊す→威力購入→兵舎→核→遺物3択→帰還→魂の祭壇→恒久強化。実際の変更・破壊・購入に応じて進み、「次へ」の連打は不要です。

枠・動く指・スポットライトで実物の操作先を示し、画面外には上下の案内と移動ボタンを出します。タップは単押しと明記。縦320/375pxと横740×320px、ネイティブの遺物/強化ダイアログ上の案内に対応。OSの動きを減らす設定では指のアニメを止めます。

練習では敵の攻撃は無害で弾切れを防ぎ、課題以外の対象を先に壊せません。練習の小さな城・報酬・強化は専用状態で管理し、通常の持ち物/残高/進行はそのまま復元します。通常セーブを削除しません。スキップ可、専用キー `cannon-castle-tutorial-v1` に途中保存し、再読み込みから続きへ戻れます。再練習しても通常報酬や無料の恒久強化を得られません。終了時は遅延している次城/遺物の処理も無効にします。

64件の単体テスト・ビルド成功。ローカル実ブラウザで砲撃/装置収益/購入/兵舎/核/遺物/次城/帰還/恒久購入と元の50魂片・持ち込み・未取得の恒久ノード復元を確認。購入段階と遺物段階からの再読み込み再開、横向き3択、320pxへの回転を確認。実機iPhone・実機セーフエリア・機内モードは未確認。公開結果と本番スクリーンショットは後述の公開検証に記録します。
