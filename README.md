# 大砲でお城をくずせ！

城をタッチして砲撃する3Dインクリメンタルゲーム。

## 遊び方と破壊率

- 城のブロックをタッチすると、その場所に発射。
- 吹き飛んだブロックや瓦礫も再び狙って破壊可能。
- 破壊率 = 1 − 全ブロックの残りHP合計 / 最初のHP合計。
- 大きく崩れたブロックは一度だけ60ダメージ。爆風は繰り返しHPを減らす。
- 画面外へ大きく飛び出したブロックは回収され、破壊扱いになります。
- 95%破壊すると残り5%の細かい瓦礫を自動回収し、100%でクリア。
- コインで破壊力・装填速度・自動砲撃を強化。

## ローカル起動・検証

Node.js 20以上。npm依存パッケージのインストールは不要。

```sh
npm test
npm run build
npm run dev
```

http://localhost:3000 を開いてください。

## Vercel

GitHubにアップロード後、Vercelの Add New → Project でリポジトリを選択。
Framework Preset: Other / Build Command: npm run build / Output Directory: dist。
vercel.json に設定済み。環境変数不要。

## 実装と制限

Three.js 0.160.1 と cannon-es 0.20.0 をバージョン固定のCDNから読み込み。
CDNへの初回通信が必要。WebGLが使えない環境はCPUによる3D透視投影で描画します。進行状況はまだ保存しません。
単体テスト・静的ビルドを確認。ブラウザでのWebGL動作は未検証。

## PWA・再生演出

Safariの共有 → ホーム画面に追加でアプリとして起動できます。対応ブラウザではインストールボタンも表示。Service Workerの初回準備完了後は、3Dライブラリを含めてオフラインで起動できます。準備中に接続を切るとキャッシュが完成しない場合があります。

「城を再生」および「次の城へ」で、瓦礫が元の配置へ逆再生のように戻ります。組み立て中は発射を止め、OSの動きを減らす設定では即時復元します。
