## ユーザーの方向性

正体不明の主人公「灰の人」と旅の記憶を持つ魂。未来の崩壊を止めるため過去の城を壊し、技術・資材を回収する。城は沈黙し、兵士だけがなぜか反撃。王や支配者は登場させない。

毎回の旅で日数を伸ばすローグライト型。敵の発展と遺物の恩恵/代償で、前回4日・今回は2日などの差を楽しむ。不要な説明やボタンを増やさず、スマホ操作優先。中世の重い石/真鍮/灰の色調、魂の光は控えめ。AAA品質に発展させるUI/UXの土台を希望し、性能を重視。サブエージェントの評価を行う。

## 実装済みのループ

ホーム→魂の祭壇/灰の器の準備→旅立つ→城と兵舎/兵を攻撃→クリアで3択→選ぶとフェードして次の日→主砲HP0または帰還でホーム。

- 通常強化3種と旅の強化網18ノードはコインで購入。全取得可能な前提DAG。
- 旅の開始でコイン・通常強化・旅の網・追加砲台・遺物・城報酬履歴を初期化。恒久側の開始コイン能力だけ反映。
- 恒久強化網8ノードは魂片で購入。HP100→200、灰の器40→90、威力、開始コイン、魂獲得を強化。
- 灰の器：石弾1、鉄弾3、炸裂弾4、修理キット5の「灰の重み」。数量入力で灰の高さが変化。上限超過/弾0では出発不可。ホームの準備物資は無料で補充。
- 石弾は標準、鉄弾は威力と衝撃、炸裂弾は広い爆風。全砲台で残数を共有、二連射も実発射分を消費。残弾のある種類へ自動切替。修理はHP35、満タンなら消費しない。
- 兵舎から最大12兵。無言の兵が歩いて主砲へ赤い弾を発射。敵弾最大24。兵舎を壊すと新規出現停止、兵士にも砲撃可能。主砲HP0で魂片を銀行に加算して帰還。
- クリアで8遺物から重複なし3択を抽選。効果/代償は必ずセット、同一遺物の重ね掛け可。選択後320msずつの暗転→城の逆再生。選択だけ手動、次の城ボタンは不要。
- 元のadvance能力は強制3択フローに合わせ「時代の収集家」（爆風威力+15%）へ変更。IDは互換性のためadvanceを維持。
- 初日はquiet固定、以降quiet/armor/legion/embers/fracturedを抽選。HP、兵出現頻度、敵火力、収益が変化。結果を保存してリロード抽選を防ぐ。
- 会話9章：intro、departureFirst、firstClear、firstReturn、altarFirst、day2/3/5/10。灰の人/魂の立ち絵、次へ、読み飛ばし、既読保存、会話中の戦闘停止。城は話さない。10日目で未来の朝が一度戻るが城/魂の謎は残す。

## 技術・ファイル

- game.js：Three/Cannon、城/支持/攻撃、経済・画面モードの統合。
- castles.mjs / damage.mjs / collision.mjs：5城の配置、材質HP/重さ/建物ID、崩壊、接触ゲート、火薬/宝物、連鎖。
- turrets.mjs / assembly.mjs：既存の俯瞰配置と逆再生。維持。
- progression.mjs / network.mjs：18能力と共通の全画面網（祭壇も同じUIで別データ）。ドラッグ/ピンチ、前提と購入、キーボード時のパン。
- expedition.mjs / journey-save.mjs：恒久8能力、灰の器、出発/消費/修理、v2保存。
- enemies.mjs / threats.mjs / relics.mjs / loot.mjs / story.mjs：敵、日ごとの変化、遺物、3択、会話。
- feedback.mjs：即加算と独立した装飾コイン、連鎖音、消音/背景停止。
- style.css / art.css：構造と中世UIテーマ。必要なUIはホーム/祭壇/戦闘/旅の網/遺物/会話。
- assets/：AI生成PNG原本9点、配信用WebP9点、prompts.md。見た目とアルファは保持した形式変換。PNG20.4MB→WebP12.5MB。画像デコードで可視画素とアルファが一致することを確認。PWAアイコンは生成遺物から書き出し。

## 保存と互換

キーcannon-castle-journey-v2、version2。メタ：screen、souls、altarOwned、loadout、sound、bestDay、journeys、storySeen。run：coins/stage/levels/owned/turrets/auto、HP、inventory、selectedAmmo、journeySouls、relics、pendingChoices、threat、報酬履歴。

購入・配置・画面移動・pagehide・背景移行は即保存、戦闘変更は約1秒間隔。途中の物理位置/敵位置は保存せず原型から再開。3択保留は復元し、選択と次の日を暗転前に保存。帰還はscreenをhomeにしてから保存し二重銀行加算を防ぐ。

旧cannon-castle-save-v1は保持し、初回にクリア数×5（上限100）の魂片へ移行。壊れた保存/使用不可でも起動。`?castle=1..5`は保存しない建築プレビュー。通常ダメージ収益は組み直し/再開で再獲得できる試作仕様。宝物とクリアボーナスは同じ旅の同日で重複しない。

## PWA・性能

キャッシュv10、HTML/CSS/全ローカルimportを?v=10。SWのSHELLは新規モジュールとWebP全9点を含む。アプリnetwork-first、CDNcache-first、旧cannon-castle-*を削除。変更時はSW/HTML/importを一緒に更新。初回素材+CDNキャッシュ完了前にオフラインへ切り替えない。

描画倍率上限1.4。敵12、敵弾24、自弾80、粒子180、装飾コイン24。共有geometry/materialを使い、城の個別マテリアル/亀裂/旗/粒子を再生時に解放。ホーム・会話・網では物理/描画停止。CPU描画フォールバックはあり、テクスチャ/プレイヤースプライトはWebGL側の表現が中心。
